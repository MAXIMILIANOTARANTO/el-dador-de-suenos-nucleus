# Patrones de Conexión de Modelos de IA (2026)

## Patrones Recomendados por El Dador de Sueños

### 1. Orquestación con LangGraph
- Para flujos complejos con estado y múltiples agentes.

### 2. Multi-Agente con CrewAI
- Cuando se necesitan roles especializados colaborando.

### 3. Gateway Unificado (Bifrost u similar)
- Para routing, fallback y observabilidad centralizada.

### 4. Model Context Protocol (MCP)
- Estándar para conectar modelos con herramientas externas.

### 5. RAG Agentic + GraphRAG
- Para sistemas de conocimiento avanzados.

### 6. Arquitecturas Multi-Model
- Combinar modelos especializados (razonamiento + visión + código).
